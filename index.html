PreviewLocker Demo Preview

Static preview page for PreviewLocker GitHub Pages demos

This is a demo preview deployment used to show how PreviewLocker can protect, inspect, and report on preview environments before teams share them more widely.

Locked preview links

PreviewLocker can generate locked, expiring links so internal reviewers can access preview deployments without sharing a raw public URL.

Indexing and exposure checks

PreviewLocker can scan preview URLs for indexing risks, exposed debug paths, and assets such as source maps that should not be broadly accessible.

Pull request comments

PreviewLocker can post a grouped security report directly on pull requests so reviewers see sharing guidance without leaving GitHub.

Optional workflow enforcement

PreviewLocker can optionally fail risky preview workflows when the configured risk threshold is met, helping teams block unsafe sharing patterns.

Demo note This GitHub Pages site is intentionally simple and includes an exposed source map demo file at assets/app.js.map so PreviewLocker checks have something realistic to report against.

Use this page as a safe demonstration target for PreviewLocker comments, scan reports, and fail-on-risk workflow tests.
